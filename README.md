# mindobirdwatching-site
Staging and production site for mindobirdwatching.com

Maps decision tools (2026-10-03): Audience scopes distinguish Ecuador, known international countries and worldwide including unknown origins. Opportunity cards require 20 sessions plus growth, 70% engagement or recorded inquiry-cohort bookings; sorting is by recorded bookings then volume, without individual visit attribution. Lodging review links open a read-only filtered CRM queue using Ecuador creation dates and canonical country names. Invoice reconciliation links point to existing accounting/CRM review surfaces; no automatic record merging occurs. Monthly seasonality uses country-day session sums and separately reconciled completed-booking timelines, with an optional prior-year outcome request and explicit unavailable values. Financial totals remain unavailable until a verified aggregate ledger feed is connected; quotes/status labels are never treated as revenue. Tests cover thresholds, missing evidence, audience scopes and review filters.
