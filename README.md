# mindobirdwatching-site
Staging and production site for mindobirdwatching.com

Maps decision tools (2026-10-03): Audience scopes distinguish Ecuador, known international countries and worldwide including unknown origins. Opportunity cards require 20 sessions plus growth, 70% engagement or recorded inquiry-cohort bookings; sorting is by recorded bookings then volume, without individual visit attribution. Lodging review links open a read-only filtered CRM queue using Ecuador creation dates and canonical country names. Invoice reconciliation links point to existing accounting/CRM review surfaces; no automatic record merging occurs. Monthly seasonality uses country-day session sums and separately reconciled completed-booking timelines, with an optional prior-year outcome request and explicit unavailable values. Financial totals remain unavailable until a verified aggregate ledger feed is connected; quotes/status labels are never treated as revenue. Tests cover thresholds, missing evidence, audience scopes and review filters.

### Inquiry follow-up and reporting health

The maps page receives aggregate follow-up counts from the existing authorized recorded-outcomes workflow. Counts use inquiries created in the selected date range and their current recorded state as of the Ecuador review day; cancellation cards therefore represent cancelled cohort inquiries, not dated cancellation events. Archived/duplicate rows are excluded and repeated inquiry IDs are removed. Queues can overlap. New-contact review requires new status and at least two calendar days with no usable contact date; quote aging requires an explicit quote-sent date at least seven days old and no newer recorded contact. Missing dates are disclosed. Payment review uses explicit CRM statuses, never quote values or assumed outstanding balances. First-response timing requires explicit first-response timestamps and displays its sample coverage; last contact is never a substitute. The CRM queue uses the same shared predicates and geographic/date filters.

Reporting health checks both GA4 comparison periods, retrieval freshness (24-hour review threshold), country/city/page identification, reporting limits, missing source dates, reconciliation and follow-up availability. Checks run on load/refresh; they are not a scheduled alert service. Missing feeds remain unavailable rather than zero. Expanded details include source-review actions. No guest identifiers are returned to maps or briefings.
